# LUT resources

The LUT image assets used by the project owner are proprietary and are not
distributed with the open-source repository.

Place locally owned compatible LUT PNG resources in this directory to make
them available to `ImageProcessor`. Files in this directory are ignored by
Git except for this notice.

Maintainers with access to the private Oxide LUT repository can install the
official asset set from the repository root with `./Scripts/install-luts.sh`.
